# Revyy browser extension, "Quiz any page"

A tiny Chrome/Edge (Manifest V3) extension that turns the page you're reading, 
or just the text you've selected, into a Revyy quiz in one click. It **captures
and hands off**: it never generates anything itself, it just carries the text to
revyy.app, where you're signed in and generation happens. That keeps the
extension dumb, safe, and impossible to abuse for free API usage.

## How it works

1. You click the Revyy toolbar button on any page.
2. The popup reads the page's main text (or your current selection) and shows a
   preview. You pick a format + question count.
3. On **Make quiz →**, the capture is stashed in `chrome.storage.local` and a new
   `revyy.app/app` tab opens.
4. A content script on revyy.app moves the capture into the page's
   `localStorage` (`revyy_import`) and nudges the app.
5. The web app (`src/StudyQuiz.jsx`) reads `revyy_import` on load, drops the text
   into the **Text** tab, and jumps to the setup screen, ready to generate.

Nothing is sent anywhere except to Revyy. The only host permission is
`https://revyy.app/*` (for the hand-off); page reading uses `activeTab`, which
grants access only to the tab you clicked on, only at that moment.

## Files

| File | Role |
|------|------|
| `manifest.json` | MV3 manifest (activeTab + scripting + storage; content script on revyy.app) |
| `popup.html` / `popup.js` | Toolbar popup: capture, preview, pick options, hand off |
| `content-revyy.js` | Runs on revyy.app: moves the capture into the page and nudges the app |
| `icon16/48/128.png` | Toolbar/store icons (generated by `_geticon.mjs`) |
| `_geticon.mjs` | Throwaway icon generator, run `node extension/_geticon.mjs` to rebuild the PNGs |

## Load it locally (to test)

1. Go to `chrome://extensions` (or `edge://extensions`).
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this `extension/` folder.
4. Pin "Revyy, Quiz any page", open any article, and click it.

> Local testing hits the live `https://revyy.app`. To test against a local dev
> server, temporarily change `REVYY_URL` in `popup.js` and the `matches` /
> `host_permissions` in `manifest.json` to your dev origin (e.g.
> `http://localhost:5173/*`).

## Publish to the Chrome Web Store

1. Zip the **contents** of this folder (not the folder itself), excluding
   `_geticon.mjs` and this README:
   `manifest.json`, `popup.html`, `popup.js`, `content-revyy.js`, `icon16.png`,
   `icon48.png`, `icon128.png`.
2. Create/《use》a [Chrome Web Store developer account](https://chrome.google.com/webstore/devconsole)
   (one-time $5 fee) and upload the zip.
3. Fill in the listing (a 128px icon, screenshots, description, privacy note, 
   "reads the current page only when you click the button; sends it only to
   revyy.app") and submit for review.

Edge Add-ons and Firefox (with minor `browser.*` shims) accept the same package.
